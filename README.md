# ScreenSound

Projeto desenvolvido em C# durante meus estudos de desenvolvimento Backend.

## Sobre o projeto

O ScreenSound é uma aplicação de console para gerenciamento de artistas e músicas,
permitindo cadastrar, consultar e organizar informações relacionadas a músicas.

## Tecnologias

- C#
- .NET
- Entity Framework Core
- SQL Server
- LINQ

## O que aprendi

Durante o desenvolvimento do projeto, pratiquei conceitos de:

- Programação Orientada a Objetos
- Entity Framework Core
- Migrations
- Banco de dados
- LINQ
- Relacionamento entre entidades
- Organização de projetos em C#
